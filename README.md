# FlueSight X

Public pages for the FlueSight X iPhone and iPad app, served with GitHub Pages:

- Home: https://zephyranthess.github.io/FlueSight-X/
- Support: https://zephyranthess.github.io/FlueSight-X/support.html
- Privacy Policy: https://zephyranthess.github.io/FlueSight-X/privacy_policy.html
- Terms of Use: https://zephyranthess.github.io/FlueSight-X/terms_of_use.html

`app_store_descriptions/` holds the App Store listing text. The pages are generated from the same source as the in-app Privacy Policy and Terms of Use, so the app, the website and the store always say the same thing.
